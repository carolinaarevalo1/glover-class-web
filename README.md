# Glover Class

Landing page de La Glover Class.

## Desarrollo local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue

Este sitio es HTML estático puro — se puede publicar directamente en Netlify, Vercel o GitHub Pages sin build.
